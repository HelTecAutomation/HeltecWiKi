The **RC3262** is a compact IoT development board featuring the **ESP32-S3R8** MCU and **SX1262** LoRa Module. It integrates Wi-Fi, Bluetooth 5.0/BLE, and LoRa connectivity, while supporting a **solder-free modular design** for flexible expansion. Compatible with Arduino, PlatformIO, and ESP-IDF, it provides an efficient platform for rapid IoT development.

## Product Characteristics

- ESP32-S3R8 + SX1262 LoRa platform with Wi-Fi, Bluetooth 5.0/BLE, and modular RF expansion.
- Supports Arduino, ESP-IDF, PlatformIO, and MicroPython.
- Compatible with Meshtastic, MeshCore, and Home Assistant ecosystems.
- Compact solder-free design for rapid integration.

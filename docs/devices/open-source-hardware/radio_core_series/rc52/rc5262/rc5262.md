The **RC5262** is a compact development board featuring the Nordic **nRF52840 MCU** and **SX1262 LoRa transceiver**, supporting **Bluetooth 5.0/BLE** and **LoRa** for flexible wireless connectivity with ultra-low power consumption. Its **solder-free plug-in design** simplifies prototyping and hardware integration. The RC5262 supports Arduino, PlatformIO, and nRF Connect SDK for efficient application development.

## Product Characteristics

- nRF52840 MCU + SX1262 LoRa transceiver with Bluetooth 5.0/BLE and ultra-low power consumption.
- Supports Arduino, PlatformIO, and nRF Connect SDK.
- Four-Row Dual-Sided, Solder-Free Expansion.
- Board-to-board interface for modular hardware expansion.

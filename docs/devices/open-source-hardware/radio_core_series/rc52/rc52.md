The **RC52 Series** is a compact IoT development platform featuring the **nRF52840 MCU** with an **optional SX1262 LoRa module**, supporting Bluetooth 5.0/BLE and optional LoRa connectivity. It features flexible expansion interfaces, including **Four-Row Dual-Sided Expansion** with a **Solder-Free Plug-In Design** and a **B2B Expansion Interface**, and supports Arduino, PlatformIO, and other development environments for efficient IoT development. The following sections provide detailed user documentation for each product.


:::tip
**More Modules** may be added in the future, providing additional connectivity options for different application scenarios.
:::

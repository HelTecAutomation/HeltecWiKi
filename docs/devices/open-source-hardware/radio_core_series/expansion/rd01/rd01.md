**RD01** is an expansion enclosure based on the **RC32**, designed primarily for **Home Assistant** applications. It integrates six sensor interfaces, comprising three **B2B interfaces** for direct connection of compatible sensor modules and three external interfaces for sensor connection via dedicated adapter cables. The external interfaces are accessible without opening the enclosure, providing a convenient solution for connecting external sensors.

## Product Characteristics

- Integrates **six dedicated sensor interfaces** for flexible sensor expansion.
- Supports direct connection of compatible sensor modules through three dedicated interfaces.
- Provides three externally accessible interfaces for connecting external sensors via dedicated adapter cables without opening the enclosure.
- Designed primarily for sensor integration with **Home Assistant**.

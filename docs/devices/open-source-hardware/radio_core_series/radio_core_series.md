title: Radio Core Series

**The RadioCore Series** is a compact system-level development platform that enables flexible integration of various MCUs and RF modules for a wide range of IoT applications. It currently supports multiple MCU platforms, including **ESP32-S3R8, ESP32-C6, and nRF52840,** providing developers with flexible hardware options for different application requirements.

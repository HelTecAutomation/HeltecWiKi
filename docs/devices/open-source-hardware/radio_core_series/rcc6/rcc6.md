The **RCC6 Series** is a compact IoT development platform featuring the **ESP32-C6 MCU** with an **optional SX1262 LoRa module**, supporting 2.4 GHz Wi-Fi, Bluetooth 5.0/BLE, and optional LoRa connectivity. It features flexible expansion interfaces, including **Four-Row Dual-Sided Expansion** with a **Solder-Free Plug-In Design** and a **B2B Expansion Interface**, and supports Arduino, PlatformIO, and ESP-IDF for efficient IoT development.
The following sections provide detailed user documentation for each product.


:::tip
**More Modules** may be added in the future, providing additional connectivity options for different application scenarios.
:::

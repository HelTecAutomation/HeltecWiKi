The **RCC662** is a compact IoT development board featuring the **ESP32-C6 MCU** and **SX1262 LoRa** Module, supporting 2.4 GHz Wi-Fi, Bluetooth 5.0/BLE, and LoRa connectivity. With a solder-free design and support for Arduino, PlatformIO, and ESP-IDF, it provides an efficient platform for IoT development.

## Product Characteristics

- ESP32-C6 + SX1262 LoRa Module with Wi-Fi, Bluetooth 5.0/BLE, and modular RF expansion.
- Supports Arduino, ESP-IDF, PlatformIO, and MicroPython.
- Compatible with Meshtastic, MeshCore, and Home Assistant ecosystems.
- Compact solder-free design for rapid integration.

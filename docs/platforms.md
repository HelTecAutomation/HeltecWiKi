Heltec Online Platforms are software platforms independently developed by Heltec for different applications and use cases. The current platforms include **F&T**, **SnapEmu**, and **MQB**.

## F&T System

The Heltec **[F&T system](/docs/platform/f&t/)** is a MeshCore-based firmware system designed for communication and coordination between devices over a Mesh network. It provides a user-friendly interface with features such as messaging, friend finding, real-time location sharing, target guidance, and route tracking, without relying on cellular or Wi-Fi connectivity.

For more information, see the **[F&T System Documentation](/docs/platform/f&t/)**.

## SnapEmu

**[SnapEmu](/docs/platform/snapemu/)** is an open-source IoT platform supporting **LoRaWAN** and **MQTT**. It provides device management, data decoding, visualization, and low-code upstream/downstream processing to simplify IoT development, deployment, and debugging.

For more information, see the **[SnapEmu Documentation](/docs/platform/snapemu/)**.

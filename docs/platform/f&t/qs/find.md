:::note
Find Friend is currently supported only on the **[Mesh Node T1](/docs/devices/open-source-hardware/nrf52840-series/mesh-node-t1/)**.
:::

:::danger
Before using **Find Friend**, make sure **Location Sharing** is enabled under the **[GPS Setting](/docs/platform/f&t/qs/gps)** on the device being located.
:::


## Access Find Friends

1. **Double-press** the **Button1/2** to open the **Function Selection** menu.
2. Select **Find Friend**.
3. Press and hold the **Button1/2** to enter the **Find Friend** menu.



In the **Find Friend** menu, press and hold **`Enable`** to activate the function.

---

## Select Find Friend Mode

Find Friend provides two modes: **Friend Mode** and **Waypoint Mode**.

### Friend Mode

Find nearby devices detected by the current device.

1. Select **Friend** under **Mode**.
2. A **Friend** selection box appears below the **Mode** selection box, where you can select the device you want to find.
3. Press and hold **Button 1/2** to confirm the selection.




### Waypoint Mode

It allows you to set a specific location as a target point using either your current location or manually entered coordinates.

1. Select **Waypoint** under Mode.
2. A Waypoint selection box appears below the Mode selection box. Select one of the following options:
   - **Current Location:** Use the device's current coordinates as the camp location.
   - **Manual Input:** Manually enter the coordinates of the desired camp location.

3. If Manual Input is selected, enter the desired coordinates and select OK to save the location.

---


After a target device or camp location is selected, the **compass on the screen points toward the target**, providing real-time directional guidance to help you locate the target.

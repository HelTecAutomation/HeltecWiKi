>After [flashing the F&T firmware](/docs/platform/f&t/flash), the device automatically enters the Home screen.

## Access System Setting

1. Double-press the **[Navigation Button](/docs/platform/f&t/qs/#navigation-button)** to open the Function Selection menu.
2. Select System.
3. Press and hold the **[Navigation Button](/docs/platform/f&t/qs/#navigation-button)** to enter the System menu.

## System Menu


*The **System** menu provides the following settings and device management options:*

- **Region:** Select the appropriate [**Region**](/docs/devices/general-docs/lorawan-instructions/lorawan_frequency_plans_by_country) according to your location and local regulations.

- **Repeat Mode:** Enable or disable packet forwarding for other MeshCore nodes to help extend network coverage.

- **Screen Off:** Set the time before the screen automatically turns off.

- **Bluetooth:** Enable or disable **Bluetooth** for wireless connections with the companion app.

- **Factory Reset:** Restore the device to its factory default settings.

- **Clear Data:** Clear stored data from the device.

- **Buzzer:** Enable or disable the buzzer on supported devices.

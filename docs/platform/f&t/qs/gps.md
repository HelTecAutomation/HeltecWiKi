>After **[flashing the F&T firmware](/docs/platform/f&t/flash)**, the device automatically enters the Home screen.

## Access GPS


1. Double-press the **[Navigation Button](/docs/platform/f&t/qs/#navigation-button)** to open the Function Selection menu.
2. Select GPS.
3. Press and hold the **[Navigation Button](/docs/platform/f&t/qs/#navigation-button)** to enter the GPS menu.

## GPS Menu

The **GPS Menu** provides the following options:

- **GPS:** Turns the GPS function on or off. Enable this option before using GPS-related features.

- **Location Sharing:** Shares the device's location with other devices on the Mesh network, allowing them to detect your location.  

:::note
To use **Find Friend**, the device being located must have **Location Sharing** enabled.
:::

- **GPS Track:** Enables GPS-based track recording for the **Track Recording** feature. This option must be enabled before using **Track Recording**.

:::tip
If **GPS** is disabled, enabling **Location Sharing** or **GPS Track** will automatically enable **GPS**.
:::

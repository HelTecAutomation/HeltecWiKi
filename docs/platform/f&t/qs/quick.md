After **[Flashing the F&T Firmware](/docs/platform/f&t/flash)**, the device automatically enters the **Home** screen. From the **Home** screen, see [**Navigation Button**](/docs/platform/f&t/qs/#navigation-button) for instructions on accessing the **Quick Access Menu**.





The **Quick Access Menu** provides the following options:

* **QuickPing:** Provides **Send Message** and **Send Advert**.
* **Compass:** Used to calibrate the device's 9-axis sensor.

:::tip
The **Compass** page is currently available only on the **Mesh Node T1**.
:::

---

### QuickPing

| Function | Description |
|---|---|
| **Send Message** | Sends messages to other devices on the Mesh network. |
| **Send Advert** | Broadcasts the device's information to the Mesh network, allowing other devices to discover or update information such as the **Device ID** and **Device Name**. |

**To send a message:**

1. Select **Send Message**.
2. Select the **sending mode** and target.
3. Select a preset message or enter a custom message using the built-in keyboard.

The following sending modes are available:

* **Broadcast:** Sends a message to all available devices on the Mesh network.
* **Group:** Sends a message to a specific group.
* **Personal:** Sends a message to a specific device for point-to-point communication.

### Compass

The **Compass** page is used to calibrate the device's 9-axis sensor.

To calibrate the sensor:

1. Enter the **Compass** page.
2. Press and hold **Button1** or **Button2** to start calibration.
3. Follow the on-screen instructions to complete the calibration.

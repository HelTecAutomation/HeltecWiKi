# Information Display

The **Information Display** section provides an overview of device information, received messages, and current radio parameters.


## Access a Function

1. Double-press the **[Navigation Button](/docs/platform/f&t/qs/#navigation-button)** to open the **Function Selection** menu.
2. Select the corresponding function.
3. Press and hold the **[Navigation Button](/docs/platform/f&t/qs/#navigation-button)** to enter the selected function.




## Home

The **Home** screen displays basic information about the device, including:

- **Device ID:** Displays the unique ID of the device.
- **MSG:** Displays the number of messages received by the device.
- **PIN:** Displays the PIN required to connect the device to the **MeshCore App**.

## Recent

The **Recent** screen displays messages received from other devices.

## Radio

The **Radio** screen displays the current radio communication parameters, including:

| Parameter | Description |
|---|---|
| **FQ** | Displays the current radio frequency. |
| **SF** | Displays the current spreading factor. |
| **BW** | Displays the current bandwidth. |
| **CR** | Displays the current coding rate. |
| **TX** | Displays the current transmit power. |
| **NF** | Displays the current noise floor. |
| **RSSI** | Displays the received signal strength indicator. |



## Compass



The **Compass** screen displays the following compass and sensor data:

| Parameter | Description |
|---|---|
| **HDG** | Displays the current heading. |
| **Q** | Displays the current orientation quaternion. |
| **X** | Displays the X-axis sensor value. |
| **Y** | Displays the Y-axis sensor value. |
| **Z** | Displays the Z-axis sensor value. |

:::note
The **Compass** function is currently supported only on the **Mesh Node T1**.
:::

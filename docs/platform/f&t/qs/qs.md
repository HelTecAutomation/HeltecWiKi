# Getting Started with F&T

>This guide provides a quick overview of how to start using the F&T firmware. It covers the navigation buttons, basic interface operations, and the essential settings to check after flashing the firmware.

:::danger
Before operating the device, refer to the **[Button](/docs/platform/f&t/qs/#navigation-button)** configuration for your specific device. The buttons used for **[navigation and operation](/docs/platform/f&t/qs/#navigation-buttons-actions)** may vary between devices.
:::

## Navigation Buttons Actions

See Navigation Button for instructions on accessing the Quick Access Menu.


For devices using the **PRG / USER** button:

| **PRG or USER** Button Action | Function |
|---|---|
| **Single press** | Move to the next option |
| **Press and hold** | Select or confirm the current option |
| **Double press** | Open the Function Selection menu or return to the previous screen |
| **Triple press** | Open the **Quick Access menu** |

:::note
When you first enter a function interface, no option is selected. **Press and hold** the PRG/USER button to activate the selection box. Then, **single-press** to move the selection box and **press and hold** to confirm.
:::


---
For the touchscreen version of the **WiFi LoRa 32 Expansion Kit V2**:

| Button   | Single Press                                   | Press and Hold                                                       | Double Press                                                          |
| -------- | ---------------------------------------------- | -------------------------------------------------------------------- | --------------------------------------------------------------------- |
| **USER** | Move to the **previous option** or **wake** the screen | Press and hold for 2 seconds to select or confirm the current option | Open the **Function Selection** menu or **return to the previous screen** |
| **IO**   | Move to the **next option** or **wake** the screen     | Press and hold for 2 seconds to select or confirm the current option | Open the **Quick Access Menu** |

### Touch Interaction


- **Tap / Long press on the screen:** Select an option or enter the corresponding function.
- **Double tap on the screen:** Open the Function Selection menu.

## General configuration


:::tip
After **[Flashing the F&T firmware](/docs/platform/f&t/flash)**, power on the device. The device will automatically enter the **[Home](/docs/platform/f&t/qs/information#home)** screen. From the function selection menu, you can access different F&T features. Some features provide options or actions to perform, while others simply display relevant device or network **[information](/docs/platform/f&t/qs/information)**.

:::




### Check the Initial Settings

***Before using the device for the first time, check the following settings and configure them as needed.***

- **Region:** In [System setting](/docs/platform/f&t/qs/system), Select the appropriate [Region](/docs/devices/general-docs/lorawan-instructions/lorawan_frequency_plans_by_country) based on your location and local regulations before using the device for wireless communication.

- **Bluetooth:** In [System settings](/docs/platform/f&t/qs/system), enable Bluetooth if you plan to connect the device to the companion app.

- **GPS:** In the [GPS function](/docs/platform/f&t/qs/gps), enable GPS if you need to use location-related functions.

:::warning
GPS functions require compatible GPS hardware. The first GPS fix may take some time. For initial use, keep the device in an open area for better reception.
:::

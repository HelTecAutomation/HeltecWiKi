The Heltec **F&T system** is a **[MeshCore-based firmware](https://meshcore.io/)** system designed to provide reliable communication and coordination between devices over a Mesh network. It features a **User-Friendly UI** and integrates practical functions such as messaging, friend finding, real-time location sharing, target guidance, and route tracking, enabling users to communicate and share location information without relying on cellular or Wi-Fi connectivity.

## Getting Started

To get started with F&T:

1. Check the **[Supported Devices](/docs/platform/f&t/devices/)** section to confirm that your device is supported.
2. **[Flash the F&T firmware](/docs/platform/f&t/flash)** to the supported device.
3. Follow the **[Quick Start](/docs/platform/f&t/qs/)** guide to configure the device and start using the F&T system.
4. Refer to the feature-specific documentation for detailed information about individual F&T functions.
